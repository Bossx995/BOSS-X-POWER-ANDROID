# BOSS Premium Mic

A rebranded WhatsApp Web microphone-processing extension based on the supplied project. It uses high-output gain with compressor/limiter protection; it cannot guarantee a fixed sound-level increase because microphones, devices, and call settings vary. Keep speaker volume comfortable.

Load the extracted folder as an unpacked extension in a compatible Chromium browser, open WhatsApp Web, reload the tab, and test with a trusted contact.


BOSS X PRIME MIC gain update: the Gain slider supports 0-50 dB, with a conservative 18 dB default. Start around 14-20 dB and increase gradually; 50 dB can cause severe clipping/distortion and does not guarantee a 50x perceived loudness increase. Limiter protection remains enabled.


## Secure access screen
This build includes the BOSS EGO artwork supplied for the popup lock screen. Password: xro_bikram919. The unlock flag is stored locally in the browser profile. The password is embedded in extension code, so this is a casual UI lock, not strong security; it is not a server-based cross-device login. Reinstalling or clearing extension/site data may require unlocking again.


Update: Blue & White theme, adjustable Noise Gate (with threshold control), and existing clarity/voice presets. Noise Gate is a simple level-based gate, not AI noise cancellation; tune the threshold carefully to avoid cutting off quiet speech.
